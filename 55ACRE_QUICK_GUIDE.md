## 🎨 Design Guidelines

### When to Use Each Color

**Black (#000000)**
- Primary buttons
- Headings
- Navigation
- Borders (strong)
- Important text

**Dark Gray (#1F2937)**
- Hover states
- Gradients
- Secondary backgrounds
- Softer borders

**Light Gray (#F3F4F6)**
- Section backgrounds
- Card backgrounds
- Input backgrounds
- Subtle accents

**White (#FFFFFF)**
- Primary button text
- Body backgrounds
- Text on dark backgrounds
- Icons on dark backgrounds

## 🔧 How to Customize

### Change the Brand Name
Search for "55acre" in:
- `Navbar.jsx`
- `Footer.jsx`
- `HomeModern.jsx`

Replace with your preferred name.

### Change a Color
Search for the color code and replace:
- Black: `#000000` or `bg-black`, `text-black`
- Dark Gray: `#1F2937` or `bg-gray-800`
- Light Gray: `#F3F4F6` or `bg-gray-50`
- White: `#FFFFFF` or `bg-white`, `text-white`

### Update Button Styling
Find `.bg-black` or `.bg-white` classes and modify.
